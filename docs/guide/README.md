# The 3B onboarding walkthrough (to be written)

This folder will hold the step-by-step walkthrough of the kit: the guide a new builder or CSE reads first. It's written with `prompts/02-3b-build-onboarding-guide.md` (milestone M2) and reviewed in a fresh session before merge.

## Planned chapters

1. **Why this method:** the problem with prompting alone; what the gates buy you.
2. **The pieces:** official skills, kit skills, subagents, hooks, the two repositories. One diagram.
3. **Setup:** editor plus MCP over OAuth, pinned skills, CLI, engagement repo plus `space/`.
4. **Phase 0, readiness:** a worked example readiness report.
5. **Phase 1, discover and spec:** a worked backlog and spec for a sample alert-triage workflow.
6. **Phase 2, build to Live:** branch, step tests, fixtures, PR, review scorecard, merge. Screenshots of each gate.
7. **Phase 3, adding AI safely:** choosing a shape, output schemas, approvals, the eval set.
8. **Phase 4, MCP:** editors on MCP; serving read-only tools from a workflow; calling a vendor's MCP server.
9. **Phase 5, operate and hand over:** runbooks, autofix review, the weekly review, conventions in every space.
10. **Reference:** status labels, decision records, the VERIFY register, glossary.

Every chapter uses synthetic examples, labels each 3B capability with its status, and links the public 3B docs.
